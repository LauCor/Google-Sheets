# 📊 Dashboards en Google Sheets

Este proyecto contiene dos dashboards desarrollados en Google Sheets que demuestran habilidades avanzadas de análisis de datos y visualización.

## 🎯 Objetivo
Crear dashboards interactivos utilizando herramientas nativas de Google Sheets para el análisis de datos.

## 🛠️ Habilidades Demostradas

✅ **Funciones avanzadas**: SUMAR, SUMAR SI, CONTAR, CONTAR SI  
✅ **Función QUERY**: Para consultas SQL-like en hojas de cálculo  
✅ **Gráficos**: Creación y personalización de visualizaciones  
✅ **Diseño de Dashboards**: Layout profesional e interactivo  
✅ **Tablas Dinámicas**: Para análisis de datos dinámicos
